# ==============================================================================
# FAIL2BAN - DERLEME VE YAYINLAMA REHBERİ
# ==============================================================================

# 1. API DERLEME (Windows x64 Single-File)
# ------------------------------------------------------------------------------
# API'yi tek bir Fail2Ban.API.exe (8 MB) olarak derlemek için:
cd Fail2Ban.API
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o ./bin/publish
# Çıktı: Fail2Ban.API/bin/publish/
# Sunucuya sadece bu klasördeki dosyaları kopyalamanız yeterlidir.


# 2. UI DERLEME VE PAKETLEME (Electron Windows Setup)
# ------------------------------------------------------------------------------
# Yeni sürüm çıkarmak için:
# 1. Fail2Ban.UI/package.json içindeki "version" değerini artırın (örn: 1.7.0 -> 1.7.1)
# 2. UI klasöründe derlemeyi başlatın:
cd Fail2Ban.UI
npm run pack:win

# Çıktı klasörü: Fail2Ban.UI/dist-electron/
# Üretilen 2 önemli dosya:
#   - "Fail2Ban Dashboard Setup x.x.x.exe"
#   - "latest.yml"


# 3. GİT VERSİYON ETİKETLEME (TAG)
# ------------------------------------------------------------------------------
# GitHub'a yeni sürüm etiketini gönderin:
git add .
git commit -m "chore: release v1.7.4"
git tag v1.7.4
git push origin master --tags


# 4. GİTHUB RELEASES İLE YAYINLAMA (KULLANICILARA OTOMATİK GÜNCELLEME)
# ------------------------------------------------------------------------------
# Adım 1: GitHub Release oluşturma sayfasına gidin:
#   https://github.com/Yagmur-Bilisim/Fail2Ban/releases/new?tag=v1.7.4
#
# Adım 2: "Fail2Ban.UI/dist-electron/" klasöründeki şu 2 dosyayı sürükleyip bırakın:
#   - Fail2Ban-Dashboard-Setup-1.7.4.exe
#   - latest.yml
#
# Adım 3: "Publish release" butonuna basın.
#
# Sonuç: Uygulamayı açık tutan veya yeniden başlatan tüm kullanıcılar
#        güncellemeyi arka planda otomatik indirir ve yükler.
